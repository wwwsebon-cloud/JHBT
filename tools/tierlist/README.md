# 빠른 티어리스트

- 5:5 승률만 봅니다 (1:1 · 3:3 안 함). 모든 지후는 **A랭크**(랭크 효과 없음) 기준.
- 판마다 무작위 10기를 5:5로 나눠 붙입니다.
- 7.8.2 **팀 실력 모델**(Bradley-Terry): 지후마다 점수 s 를 두고 `P(아군 승) = 1/(1+e^-(Σ아군 s − Σ적 s))`가 모든 판에 가장 잘 맞도록 s 를 구합니다. 같은 팀 · 상대 팀이 누구였는지 보정돼요.
- 결과는 승패(0/1) 대신 **결과 점수** `0.5 + (아군 남은 체력 − 적 남은 체력)/2` 를 씁니다. 실제 시뮬 2,400판을 반으로 나눠 비교하면 순위 일치도가 승률 0.62 → 0.71로 올라갑니다.
- 표시 승률(r5) = σ(s): 평균 팀원 4기와 함께 평균 팀을 상대로 이길 확률. 오차는 헤세 역행렬로 계산.
- 티어: 비율로 자르지 않고, 점수가 크게 벌어지는 곳에서 6개로 나눕니다 (1차원 최적 k-평균 · 한 티어 최소 2기).
- `tools/tierlist/run.sh 5.4.0` → 시뮬 → `index.html`의 `TIER_HISTORY` 맨 앞에 새 표 추가 + `BOT_TIER_LIST`(봇 덱 고르기) 교체.
- 기본 1,600판 / 병렬 4개 ≈ 5~8분 (지후 한 기당 약 120판). 더 빠르게: `run.sh 5.4.0 1000`.

- 개발자 모드 측정은 운영자 기기마다 `tiersim/{기기}` 에 올라가고, 같은 버전인 모든 기기의 판을 합쳐 계산합니다 (firestore.rules 게시 필요).
