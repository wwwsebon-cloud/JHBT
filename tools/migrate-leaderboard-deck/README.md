# 레벨 리더보드 덱 일괄 변환 (4.6.5)

4.6.5부터 레벨 리더보드에는 **1번 슬롯 덱**이 보입니다. 게임을 켜면 자동으로 바뀌지만, 그 뒤로 접속하지 않은 플레이어는 예전 "최근 덱"이 남아 있습니다.
이 스크립트는 모든 플레이어의 백업에서 1번 슬롯 덱을 읽어 리더보드에 한 번에 씁니다. 1번 슬롯이 5기가 아니거나 백업이 없으면 기본 덱(화염 · 얼음 · 힐 · 쉴드 · 독)을 씁니다.

백업은 본인만 읽을 수 있으므로 **관리자 키(서비스 계정 키)** 로 실행해야 합니다. 한 번만 실행하면 됩니다.

## 실행

1. [Node.js](https://nodejs.org) 18 이상을 설치합니다.
2. Firebase 콘솔 → ⚙ 프로젝트 설정 → **서비스 계정** → **새 비공개 키 생성** → 받은 JSON 파일을 이 폴더에 둡니다.
   - 이 키는 데이터베이스 전체 권한입니다. **저장소에 올리거나 남에게 보내지 마세요.** (`.gitignore`가 `jihoobattle-*.json`, `serviceAccount*.json`을 막아 둡니다.) 다 쓰면 콘솔에서 키를 삭제해도 됩니다.
3. 이 폴더에서:

```bash
npm install
node migrate.js --key 받은키파일.json          # 미리보기: 바뀔 목록만 보여주고 아무것도 쓰지 않음
node migrate.js --key 받은키파일.json --apply  # 실제로 쓰기
```

`updatedAt`(최근 접속)은 건드리지 않고 `deck`만 바꿉니다. 여러 번 실행해도 이미 같은 덱은 건너뜁니다.
